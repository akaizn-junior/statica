The idea

The web already has a language.

Static site generators keep inventing another one. statica doesn’t.

Use HTML for structure, CSS for style, JavaScript for behavior, and structured data when you need to generate content. statica handles the build, then gets out of the way.

How it works

HTML in. HTML out.

  • AuthorWrite valid HTML. Link data and fragments only where you need them.
  • Builddiscover → pre → parse → funnel → expand → bind → scope → emit → minify.
  • ShipDeploy plain HTML, CSS, and JavaScript anywhere static files can live.

Not just blogs

If the web can do it, your statica site can do it.

statica does not impose a frontend runtime. Build an interactive API explorer from OpenAPI JSON, documentation, catalogs, dashboards, or a tiny five-page site. At runtime, it is simply the web platform.
