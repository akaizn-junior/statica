# @statica/cli-linux-arm64-gnu

Prebuilt statica CLI binary for Linux arm64 with glibc.

statica is **Just HTML**: a blazingly fast static site generator for valid HTML.

This package is installed automatically as an optional dependency of `@statica/cli` on supported systems. Install and run the CLI through the launcher package:

```bash
npm i -D @statica/cli
npx statica build .
```
